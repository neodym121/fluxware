# fluxware

[English](README.md) · **Русский**

Загрузчик видео и музыки для терминала. Вставляешь ссылку, выбираешь качество, получаешь файл.

fluxware — интерфейс для управления с клавиатуры поверх [yt-dlp](https://github.com/yt-dlp/yt-dlp), поэтому работает с YouTube, SoundCloud, X, TikTok, Instagram, VK и сотнями других сайтов, которые поддерживает yt-dlp. Интерфейс сделан на [OpenTUI](https://opentui.com) и работает в любом современном терминале; разрабатывается и проверяется в Windows Terminal.

## Возможности

**Скачка.** Вставляешь ссылку — fluxware показывает название, автора, длительность и обложку, а под ними доступные разрешения, самое высокое первым, и вариант «только звук». Загрузка идёт прямо в карточке: полоса прогресса, скорость, оставшееся время и кнопка отмены. Можно вставить сразу несколько ссылок и скачать их все как видео или все как аудио. Ссылки на SoundCloud и другие источники только со звуком начинают качаться без лишних вопросов.

**Аудио.** OPUS и M4A с YouTube сохраняются без перекодирования, MP3 кодируется в 192 кбит/с. Обложка обрезается в квадрат и вшивается в файл вместе с метаданными.

**Пакет.** Вставь любой текст, например кусок переписки, и ссылки найдутся в нём сами, даже склеенные или без `https://`. Ссылки можно загрузить из `.txt` файла. Выбираешь видео или аудио и ограничение качества и следишь за прогрессом всего пакета.

**История.** Каждая готовая загрузка попадает в лог, сгруппированный по датам, время справа. Файл можно открыть там, куда он сохранён, скачать снова или убрать из истории. Лог можно отключить в настройках.

**Очередь.** Загрузки идут в фоне, по одной или до четырёх сразу, так что следующую ссылку можно вставлять, пока качается предыдущая. Отменённая загрузка удаляет за собой временные файлы.

**Настройки.** Контейнер видео (MP4, WEBM, MKV), формат аудио (OPUS, MP3, M4A), отдельные папки для видео и аудио, число одновременных загрузок, превью обложек, лог истории, язык интерфейса (русский или английский) и свои параметры yt-dlp, которые yt-dlp проверяет перед сохранением.

Если YouTube отдал только запасной формат низкого качества или видео скачалось хуже, чем было доступно, fluxware об этом скажет и покажет предупреждения yt-dlp, которые это объясняют.

## Установка

fluxware поставляется одним исполняемым файлом `fx.exe`, распаковывать ничего не нужно.

1. Скачай `fx.exe` из [последнего релиза](../../releases/latest).
2. Положи его в свою папку, например `C:\Tools\fx`.
3. Добавь эту папку в `Path`: открой меню «Пуск», найди «Изменение переменных среды для вашей учётной записи», выбери `Path`, нажми **Изменить**, затем **Создать** и впиши папку, например `C:\Tools\fx`. Или выполни в PowerShell со своей папкой:

   ```powershell
   [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\Tools\fx", "User")
   ```

4. Открой новый терминал и запусти `fx`.

Ещё понадобятся программы из списка ниже. Язык интерфейса выбирается по системе и переключается в настройках.

## Что нужно

- [yt-dlp](https://github.com/yt-dlp/yt-dlp): `pip install -U "yt-dlp[default]"` или `winget install yt-dlp`
- [ffmpeg](https://ffmpeg.org): `winget install ffmpeg`, нужен для склейки видео и звука, извлечения аудио и обложек
- [Deno](https://deno.com) или [Node.js](https://nodejs.org), желательно: ими yt-dlp решает JavaScript-задачки YouTube, без них YouTube иногда отдаёт только 360p

fluxware находит yt-dlp в `PATH` или как Python-модуль `yt_dlp` и при запуске предупреждает, если нет yt-dlp или ffmpeg.

## Запуск из исходников

Нужен [Bun](https://bun.sh) 1.3.14 или новее.

```bash
bun install
bun start
```

`bun run build` собирает всё в один исполняемый файл `dist/fx.exe`. Тесты: `bun test`.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Переход между вкладками разделов и окнами раздела |
| `←` `→` | Переключение разделов на панели вкладок |
| `↑` `↓`, `Enter` | Движение по спискам, выбор |
| `Esc` | Назад |
| `Ctrl+S` | Запустить пакет |
| `Ctrl+C` | Выход; если идут загрузки, нажать дважды |

Нижняя строка всегда показывает клавиши, которые работают прямо сейчас. Мышь тоже работает.

## Файлы

Настройки, лог истории и небольшой файл состояния лежат в `%APPDATA%\fluxware` на Windows, в `~/Library/Application Support/fluxware` на macOS и в `~/.config/fluxware` на Linux. Настройки прежней Python-версии переносятся при первом запуске.
